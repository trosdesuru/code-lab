# Code Lab

🚀 A space to experiment with functions, algorithms, and small JavaScript snippets.

## 📌 About
This repository is a code lab where I test and optimize JavaScript functions. It includes:
- Solutions to algorithmic challenges
- Experiments with different implementations
- Useful code snippets for everyday development

## 🛠 Technologies
- JavaScript (ES6+)
- Node.js (for running scripts)

## 📂 Structure
```
code-lab/
│── algorithms/       # Algorithmic challenges
│── snippets/         # Useful code snippets
│── experiments/      # Various JS experiments
│── README.md         # Project documentation
```

## 🚀 Getting Started
1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/code-lab.git
   ```
2. Navigate to the folder:
   ```sh
   cd code-lab
   ```
3. Run JavaScript files:
   ```sh
   node path/to/file.js
   ```
